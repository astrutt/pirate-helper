# pirate-helper
# made for https://piratesirc.com/ played on irc.2600.net/#pirates


 --- Pirate Helper Commands ---
 /palarm <HH:MM:SS> - Beeps the client when local time arrives
 /ptimer <HH:MM:SS> <msg> [num] - Sends a channel message after delay, optionally repeating [num] times
 /plist - Lists active alarms and timers (channel specific, or all if run in server window)
 /pdel <num> - Deletes a timer or alarm by its ID
 /pclear - Clears all active timers and alarms for the current channel (or globally from server window)
 /phelp - Displays this help message
 /pabout - Displays about and version information
